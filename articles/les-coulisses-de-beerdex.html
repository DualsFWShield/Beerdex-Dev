Comment est construit Beerdex ?

Beerdex est conçu entièrement en HTML, CSS et JavaScript ce qui permet de rendre l'app disponible sur n'importe quel appareil.

D'où viennent la liste des bières ?

J'ai scrappe différents site web de vente de bières afin de constituer une base de données de 1220 bières et la liste continue à se rallonger au fur et a mesure. En complément, une api permet de fournir les code barre et les bières qui ne sont pas dans ma base de données.

Combien ça coûte de faire tourner Beerdex ?

La publication sur le play store coûte 25€ et le nom de domaine coute 10€. L'app est hébergée sur GitHub.
